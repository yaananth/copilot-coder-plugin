# Security Policy

Please do not disclose suspected vulnerabilities in a public issue before a
maintainer has had a chance to assess them.

Use GitHub's private security-advisory reporting flow for
`yaananth/copilot-coder-plugin` when it is available. Otherwise, open a minimal
public issue that asks for a private contact channel and does not include exploit
details, credentials, or sensitive repository information.

Include the affected version, a clear reproduction, impact, and any suggested
mitigation. Reports are handled on a best-effort basis.
